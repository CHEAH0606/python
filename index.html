Build A Code · Python Quest

Adventure 1 · Pip’s Robot Workshop

12 missions · ages 7–10

Children store numbers and text, replace values, then combine these skills. The first Run on each mission counts towards the first-try score. Hints are recorded separately. Valid code runs even when it misses the mission goal. Each Run starts the scene and variables fresh.

This offline activity supports a small Python subset: one assignment per line, whole numbers 0–6, quoted text, and the provided move(steps) / say(name) commands. These two commands belong to this game. This is a beginner practice interpreter, not a full Python runtime. No installation or internet is needed.

Progress is kept in this open tab. Reloading or restarting clears it. Print the report before closing.
